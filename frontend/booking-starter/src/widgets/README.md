# widgets

Слой крупных UI-блоков.

- app-header/ — шапка приложения
- event-type-list/ — список типов событий
- booking-calendar/ — календарь бронирования
- booking-slots/ — список свободных слотов
- booking-summary/ — сводка бронирования
- admin-bookings-table/ — таблица предстоящих встреч
- admin-event-types-list/ — список типов событий в админке

Импортирует: features, entities, shared.
